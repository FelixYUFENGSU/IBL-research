# IBL: mouse breathing sensor fusion

Fusing thermistor, airflow, and LFP signals to study breathing rhythm and sensor agreement in mouse M1 recordings.

## Setup

See [docs/setup.md](docs/setup.md).

## Layout

- `data/` — raw/processed session data (not synced to source control)
- `docs/` — setup notes and research notes ([docs/notes.md](docs/notes.md))
- `results/` — generated figures and tables (not synced to source control)
- `scripts/` — notebooks and standalone scripts
- `src/ibl/` — reusable Python modules
- `tests/` — tests for `src/ibl`
